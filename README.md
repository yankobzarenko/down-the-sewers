## 🚀 How to Play

### **Installation / Execution**
*   **Web Build:** https://imreallyreallytired.itch.io/down-the-sewers

### **Controls**
*   `A, S, D`: Move character
	`S + Spacebar`: Jump down a compatible platform
*   `Spacebar`: Jump (Ability acquired later on)
	`Shift`: Dash (Ability acquired later on)
